This directory contains the Barents Sea formation data sets, in ED50 UTM32 (EPSG 23032).

The formations included are:
    - Bjarmeland
    - Fruholmen
    - Sto
    - Nordmela
    - Tubaen
    - Knurr (not evaluated as an aquifer with storage potential)

Sto, Nordmela, and Tubaen make up the Hammerfest Basin Aquifer. (Sto is most shallow, Tubaen is most deep)

This data was obtained from NDP, via email, since they are not downloadable from their website.
